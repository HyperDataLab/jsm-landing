# JSM landing page scan

The local page at `http://localhost:5173/` and the live JSM landing page both present JSM as a Windows desktop tool for exploring journal profiles and comparing manuscript writing style. Keep the HyperData Lab identity, light academic palette, Windows download, bilingual support, and clear note that analysis is reference information.

Before the redesign, the hero centered on journal fit and used a stylized dashboard labeled “MINH HỌA.” The feature section described manuscript analysis, journal comparison, references, and history. The process section repeated choosing a journal, uploading a manuscript, and reviewing results; the download section repeated Windows and file details; FAQ repeated format and decision caveats. The page had no dedicated use cases and the footer had no product or information pages to link.

Existing navigation destinations were:

- “Tính năng” → `#tinh-nang`
- “Cách hoạt động” → `#cach-hoat-dong`
- “Tải ứng dụng” → `#tai-ung-dung`
- “Hỏi đáp” → `#hoi-dap`
- “Cổng Lưu Trữ” was not in the rendered navigation; there was no matching section.

The JSM product source confirms journal search/profile data, manuscript style analysis, journal comparison, evaluation history, and Central SSO. The current release URL resolves to a public Windows installer. No real screenshot, privacy policy, or public support channel was found in this landing repository. Registration uses `https://auth.hyperdatalab.org/register`.
